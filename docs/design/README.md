One entry per doc, oldest first; where docs conflict, the later one supersedes. Each doc
describes the design as it stands. Start with the overview; its §10 says how the docs fit
together and how code and other docs cite a section. A new design doc is added as a dated file,
`YYYY-MM-DD-<slug>.md`, and listed here.
